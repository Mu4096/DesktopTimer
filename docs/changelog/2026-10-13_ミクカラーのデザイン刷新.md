# ミクカラーのデザイン刷新

- 日付：2026-10-13
- 種別：改善
- 関連する仕様書の章：4.2, 4.7, 4.8（新設）, 9

## 背景・目的

初回実装の見た目は最低限のもので味気なかったため、「シンプル・見やすい・操作しやすい」を保ったまま全面的にデザインし直した。配色はユーザーの希望で初音ミクの雰囲気に寄せる。内部の処理（状態遷移・設定・サービス類）は変更せず、見た目だけを変える。

## 変更内容

- テーマを `Themes/` に分離し、`App.xaml` から読み込む形にした
  - `Theme.xaml`：色・ブラシ・フォント。ティール `#39C5BB` を主役、暗いグレーを下地、ピンク `#FF5AA5` を警告色に
  - `Controls.xaml`：右クリックメニュー、ツールチップ、スクロールバー、テキストボックス、ボタン、スライダー、チェックボックス（トグルスイッチ化）、設定画面のカード
  - `TimerStyles.xaml`：タイマー本体のプリセットボタン、グリップの ⚙、進捗バー、リサイズハンドル
- タイマー本体（`TimerWindow.xaml`）
  - 角丸12の暗いカード＋ティールの細い枠。上端に両端へ消えるティールの光るライン
  - プリセットボタンはティールのグラデーション。数字（Bahnschrift）を大きく、単位を小さく表示（`LabelPartConverter` で「10分」を数字と単位に分ける）。ホバーで光彩、押すと少し縮む
  - 残り時間は Bahnschrift の大きな数字にティールの光彩。警告時・TimeUp 時は文字・光彩・枠・上端ライン・進捗バーがピンクに変わる
  - 進捗バーは音量メーター風の目盛り区切り（OpacityMask のタイル）で、先端ほど明るいグラデーション
  - グリップは点（2段×4列）、リサイズハンドルもティールの点に
  - 右クリックメニューを暗い配色・角丸・影付きにし、各項目にアイコンを付けた
- 仕様に記載のなかった表示上の判断
  - TimeUp の点滅は消灯側を完全に消さず不透明度 15% にした（点滅は維持しつつ、ちらつきを和らげるため）
  - TimeUp 中は経過時間の代わりに「♪ クリックで止める」を表示（解除方法が分かるように）
  - 仕様書 4.7 に追記し、配色などの方針を 4.8 として新設した
- 設定画面（`SettingsWindow.xaml`）
  - 2列のカードレイアウトに変更（幅 800。以前は縦に長く、画面の低いモニターではみ出しやすかった）。万一収まらない場合のため作業領域の高さを上限にしてスクロールできるようにした
  - 見出し・各カードにアイコン。チェックボックスはトグルスイッチ、スライダーは細い線＋丸つまみ、数値は Bahnschrift
  - 音源一覧は選択行をティールで強調。試聴 / 停止・削除はアイコンボタン（文言はツールチップ）
  - ホットキーの入力欄は受付中にティールの背景、登録できないキーはピンクの枠と警告
  - タイトルバーを画面と同じ暗い色にする（`TitleBarTheme`、`DwmSetWindowAttribute`。Windows 11 で色指定、Windows 10 では暗色のみ。P/Invoke は `Interop/NativeMethods` に追加）
- トレイメニュー：`TrayMenuRenderer`（WinForms の描画クラス）で同じ暗い配色に。`TrayIconService` には適用の1行だけ追加
- アプリアイコン（`Assets/app.ico`）：ティールの角丸四角に白いストップウォッチ、残り時間をピンクの扇形で表す図柄に作り直した。以前と同じく PowerShell＋System.Drawing で生成（16〜64px は 32bit BMP、256px は PNG）
- `CLAUDE.md` のプロジェクト構成に `Themes/` を追記

## 追加の調整（ユーザーの好みに合わせて）

ユーザーの確認で動作は問題なし。デザインについて次の4点の要望があり対応した。

- プリセットボタン：数字と単位をまとめて中央にしていたのを、数字だけを中央に置き、単位はその右にくっつける形に（`PresetButtonStyle` の ContentTemplate を左右同幅の * 列で挟む Grid に変更）
- 全体を角張ったデザインに（角が立たない程度の R は残す）
  - 大きな面（タイマー本体・設定のカード・メニュー）は R4、ボタン・入力欄は R3、小さな部品は R1〜2
  - 丸い部品は角の丸い四角に：トグルスイッチのつまみ、スライダーのつまみ、アイコンボタン、カード見出しのアイコン下地、グリップ・リサイズハンドルの点
  - トレイメニューの選択枠、アプリアイコンの角丸（一辺の 22% → 12%）も小さくした
- 進捗バーを「経過割合が伸びる」から「残り割合が減っていく」表示に変更（仕様書 4.2 を変更）
  - ViewModel の `Progress`（経過割合）はそのままにし、ビュー側の `RemainingRatioConverter` で 1 − 経過割合 に変換して表示する
- 進捗バーの視認性を上げた：高さ 6 → 12、目盛りを幅5＋隙間2 に、ティール（警告時ピンク）の光彩を追加、グラデーションの暗い側を明るく
- 仕様書 4.2 の図と 4.8 を更新
- ついでの修正：`TrayMenuRenderer` の内部クラス名 `ColorTable` が基底クラスのプロパティ名と重なり警告 CS0108 が出ていたので `DarkColorTable` に改名（前回の確認では差分ビルドで警告が表示されていなかった）

確認：`dotnet build --no-incremental` で警告・エラー 0、`dotnet test` 68 件合格。前回と同じ確認用ハーネスで各状態の描画と設定画面の実表示を確認した。

## 待機画面のボタンの作り直し

ユーザーから「設定画面と動作中の画面はいいが、待機画面がチープに見える。フォントの種類や大きさが原因では」との指摘があった。

- 原因の切り分け：WPF で Bahnschrift の各太さを描いて比べ、合成の太字にはなっておらず正しく描画できていることを確認した。安っぽさの主因は、彩度の高いティールのベタ塗りに暗い文字を太く載せた配色と、単位「分」の極太ゴシック（Bold 13）と判断
- 4案（暗い板＋ティール数字、暗い板＋白数字＋下端ライン、深いティール塗り＋白数字、枠線のみ）を実際の待機画面として描いて比較し、ユーザーが「暗い板＋白数字＋下端ライン」を選択
- `PresetButtonStyle` を変更
  - 暗い板（`SurfaceRaisedBrush`）に白い数字（Bahnschrift SemiBold 38）＋ティールの光彩。動作中の残り時間表示と同じ見せ方にそろえた
  - 単位は Yu Gothic UI SemiBold 12 のティール
  - 下端にティールのライン（2.5）。ホバーでラインが明るくなり、板にティールがうっすら重なって周りが光る。押すとティールが濃くなり少し縮む
- 使われなくなった `AccentFillHoverBrush` / `AccentFillPressedBrush` を削除
- 仕様書 4.8 にボタンの見せ方を追記

確認：`dotnet build --no-incremental` で警告・エラー 0、`dotnet test` 68 件合格。各状態を描画して確認（ホバー・押下の見た目は実機で確認してもらう）。
