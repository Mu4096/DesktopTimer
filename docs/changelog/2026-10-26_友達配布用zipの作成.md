# 友達配布用 zip を作れるようにする

- 日付：2026-10-26
- 種別：改善
- 関連する仕様書の章：1

## 背景・目的

アプリを友達に渡したいという要望。インターネットでの公開ではなく、知人に手渡しする用途。
これまでも README の「他の PC で使う」で .NET 込みの単一 exe は作れたが、自分用の手順で、約170MB と大きく、受け取った人向けの説明（SmartScreen の警告、自動起動、削除方法）もなかった。

## 変更内容

- `tools/make-dist.ps1` を追加。単一 exe の publish から zip 化までを1回で行う
  - `EnableCompressionInSingleFile` で圧縮し、zip は約 67MB（未圧縮の exe は約 170MB）
  - `DebugType=none` で pdb を出さない
  - 展開すると `DesktopTimer` フォルダができるよう、フォルダごと zip にする。ファイル名は `DesktopTimer_YYYY-MM-DD.zip`、出力先は既定でリポジトリの隣の `DesktopTimer-dist`（リポジトリ内に出すと未追跡ファイルになるため）
  - Windows PowerShell の `Compress-Archive` は日本語のファイル名を Shift-JIS で格納するため、`ZipFile.CreateFromDirectory` に UTF-8 を指定して作る
  - スクリプトは Windows PowerShell 5.1 で日本語が化けないよう UTF-8（BOM 付き）で保存
- `tools/dist/はじめにお読みください.txt` を追加（zip に同梱する受け取った人向けの説明書）
  - 展開してから起動すること（zip の中から起動すると一時フォルダの exe が自動起動に登録されるため）、SmartScreen の進め方、初回で自動起動が ON になること、基本操作、更新方法、削除方法（先に自動起動を OFF にしないと Run キーに登録が残る）を書いた
  - メモ帳で確実に開けるよう UTF-8（BOM 付き）・CRLF
- `docs/spec.md` 1章の利用者を「開発者本人と、その知人」に変更（インストーラ・自動更新は引き続き 12章で対象外）
- `README.md` に「友達に渡す」の節を追加し、冒頭の「自分用」の表現を直した。`CLAUDE.md` / `AGENTS.md` の構成一覧に `tools/` を追記
- 版番号は付けず、zip 名の日付で区別する（仕様に記載のない判断。版番号の管理を増やさないため）

## 確認

- `dotnet build` 警告・エラーなし、`dotnet test` 142 件合格
- スクリプトを実行し、zip（67MB）ができることを確認。展開すると `DesktopTimer\DesktopTimer.exe` と `DesktopTimer\はじめにお読みください.txt` になり、ファイル名に UTF-8 フラグが付いていることを確認
- 未確認：zip から展開した exe の起動（普段使いのタイマーの自動起動登録を書き換えてしまうため自動確認はしていない）。ユーザーに確認してもらう
