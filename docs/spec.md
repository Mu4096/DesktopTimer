# デスクトップ常駐タイマー 仕様書

## 1. 概要

デスクトップの隅に常駐表示し、ボタン1回（またはショートカットキー1回）で即座に開始できるタイマーアプリ。
「準備してから始める」のではなく「気づいたら押す」ことを目的とするため、**開始操作の手数を最小にすること**を最優先の設計方針とする。

- 対象OS：Windows 10 / 11 のみ
- 利用者：開発者本人と、その知人（zip で手渡しする。インストーラ不要、ビルド成果物をそのまま実行。配布用 zip は `tools/make-dist.ps1` で作る）
- アプリ名（仮）：DesktopTimer

## 2. 技術スタック

| 項目 | 採用 |
|---|---|
| 言語 / UI | C# / WPF |
| ランタイム | .NET 10（LTS。.NET 8 は2026年11月でサポート終了のため不採用） |
| 音声再生 | NAudio（ループ再生・音量制御・mp3対応のため） |
| タスクトレイ | System.Windows.Forms.NotifyIcon（WPFから利用） |
| グローバルホットキー | Win32 `RegisterHotKey` / `UnregisterHotKey`（P/Invoke） |
| 設定保存 | JSON（`System.Text.Json`） |
| DPI | Per-Monitor V2（app.manifest で宣言） |

## 3. 状態遷移

アプリは次の4状態を持つ。Running には計り方が2種類ある（カウントダウン / カウントアップ）。

```
カウントダウン（プリセット・時間指定・アラーム）
[Idle] --プリセット開始 / 時間を指定して開始 / アラーム--> [Running] --残り0--> [TimeUp]
   ^                                              |                     |
   |------キャンセル-------------------------------|                     |
   |------------解除（クリック / キャンセルキー）--------------------------|

カウントアップ
[Idle] --カウントアップ開始--> [Running] --停止（メニュー / キャンセルキー）--> [Stopped]
   ^                                                                           |
   |------------閉じる（クリック / キャンセルキー / メニューのキャンセル）---------|
```

| 状態 | 表示 | 遷移 |
|---|---|---|
| Idle | プリセットボタン2つ | プリセットボタン押下 or ホットキー → Running（カウントダウン）/ 右クリック →「タイマー（時間指定）...」→ Running（カウントダウン）/ 右クリック →「アラーム（時間指定）...」→ Running（指定時刻までのカウントダウン）/ 右クリック →「カウントアップ開始」→ Running（カウントアップ） |
| Running（カウントダウン） | 残り時間（大）・経過時間（小。アラームでは鳴る時刻）・進捗バー | 残り0 → TimeUp / キャンセル（メニュー・キャンセルキー・長押し） → Idle |
| Running（カウントアップ） | 経過時間（大）・「カウントアップ中」（小）・1分ごとに満ちる進捗バー | 停止（メニュー・キャンセルキー・長押し） → Stopped（終わりは無く、止めるまで続く） |
| TimeUp | `0:00` を点滅表示、音をループ再生 | 左クリック or キャンセルキー → Idle / 新しく開始 → Running |
| Stopped | 止めた時点の経過時間を表示したまま「■ 停止中 ・ クリックで閉じる」 | 左クリック or キャンセルキー → Idle / 新しく開始 → Running |

- Running 中の開始操作（プリセットのボタン・ホットキー、時間指定、アラーム、カウントアップ開始）は**無視**する（実行中はプリセットボタン自体を表示せず、メニューの開始項目は無効表示）
- TimeUp / Stopped からはどの開始操作でも新しく開始できる
- 一時停止・延長機能は**持たない**

## 4. ウィンドウ仕様

### 4.1 基本

- `WindowStyle=None`、`AllowsTransparency=True`、`ShowInTaskbar=False`、`Topmost=True`
- 初回起動時の位置：プライマリモニターの右下隅（作業領域内、端から16px内側）
- 基準サイズ：幅240 × 高さ110 DIP（グリップ含む）。縦横比は固定

### 4.2 レイアウト

```
┌──────────────────────────┐
│ ⋮⋮⋮⋮ (グリップ)      ⚙ │  ← 高さ約14DIP。低コントラストで常時表示
├──────────────────────────┤
│  ┌─────────┐ ┌─────────┐ │
│  │  10分   │ │  30分   │ │  ← Idle：プリセットボタン2つ（主役）
│  └─────────┘ └─────────┘ │
└──────────────────────────┘

┌──────────────────────────┐
│ ⋮⋮⋮⋮                ⚙ │
├──────────────────────────┤
│        07:42             │  ← Running：残り時間（大）
│   経過 02:18 / 10:00     │  ← 経過時間（小）
│  ███████████████░░░░░░   │  ← 進捗バー（残り割合。時間とともに右から減る）
└──────────────────────────┘

┌──────────────────────────┐
│ ⋮⋮⋮⋮                ⚙ │
├──────────────────────────┤
│        1:12:30           │  ← アラーム：鳴るまでの残り時間（大）
│    🔔 7:30 にアラーム     │  ← 鳴る時刻（ベルは右クリックメニューと同じアイコン）
│  ███████████████░░░░░░   │  ← セットした時点からの残り割合
└──────────────────────────┘

┌──────────────────────────┐
│ ⋮⋮⋮⋮                ⚙ │
├──────────────────────────┤
│        12:34             │  ← カウントアップ：経過時間（大）
│     カウントアップ中     │  ← 停止後は「■ 停止中 ・ クリックで閉じる」
│  ████████░░░░░░░░░░░░░   │  ← 今の1分の経過割合（左から伸び、1分ごとに満ちて空に戻る）
└──────────────────────────┘
```

- プリセットボタンのラベルは設定値から自動生成（例：`10分`、`90分`）
- 時間表示は `mm:ss`。60分以上は `h:mm:ss`（カウントアップが24時間を超えても `25:00:00` のように時を増やす）
- 右下隅にリサイズ用ハンドル（マウスホバー時のみ表示）

### 4.3 移動

- **グリップ部分をドラッグした時のみ**ウィンドウを移動する
- ボタン・時間表示部分のドラッグでは移動しない（誤スタート防止）
- 移動完了時に位置を保存する

### 4.4 サイズ変更

- 右下ハンドルのドラッグで拡大縮小（縦横比固定、スケール50%〜300%）
- 設定画面のスライダーからも変更可能（同じスケール値を共有）
- 内部的には基準サイズ × スケールで描画し、レイアウトは `Viewbox` 等で比例拡大させる

### 4.5 右クリックメニュー

ウィンドウ上のどこでも右クリックで表示する。

| 項目 | 有効条件 |
|---|---|
| キャンセル（カウントアップの計測中は「停止」） | Running / TimeUp / Stopped 時のみ |
| （区切り） | |
| タイマー（時間指定）... | Running 以外（4.9 の小窓を開く） |
| アラーム（時間指定）... | Running 以外（4.10 の小窓を開く） |
| カウントアップ開始 | Running 以外 |
| （区切り） | |
| 設定... | 常時 |
| 位置をリセット | 常時（プライマリモニター右下へ） |
| 非表示にする | 常時（再表示はトレイから。9章） |
| （区切り） | |
| 終了 | 常時 |

- 「停止」はカウントアップを Idle に戻さず、結果を表示したまま止める（Stopped）。Stopped での「キャンセル」は Idle に戻す

### 4.6 誤操作防止

- Running 中の左クリックは**何もしない**（カウントアップも同じ）
- Running 中は本体（グリップ以外）の左ボタン**長押し（1秒）**でキャンセルする（カウントアップの計測中は「停止」）
  - 押してから0.3秒は何も表示しない（普通のクリックでゲージがちらつかないように）。その後、本体を暗くして中央にゲージを出し、残りの0.7秒で満ちたら実行する
  - ゲージは円形（太さ7 DIP）で、真上から時計回りに伸びる。弧の両端は丸めず直線で切る（4.8 の「丸い部品も角の丸い四角にする」の例外。四角いマス目の案も試したが、ユーザーの希望で円形にした）
  - ゲージはカウントダウンのキャンセルがピンクに ✕、カウントアップの停止がティールに ■（右クリックメニューのアイコンと同じ）
  - 一周する前に離す、ポインターが本体の外へ出る、右クリックメニューが開く、状態が変わる（残り0で TimeUp・キャンセルキー等）と中断し、何もしない
  - 実行後にボタンを離しても何も起きない（止めたカウントアップを閉じたり、待機画面のプリセットが始まったりしない）
- キャンセル（停止）手段は右クリックメニュー、キャンセルホットキー、トレイメニュー、本体の長押しのみ
- 時間指定・アラーム・カウントアップは待機画面にボタンを増やさず、右クリックメニューから使う（待機画面はプリセット2つだけに保つ）

### 4.7 色変化

- 残り時間が警告閾値（デフォルト1分）以下になったら、残り時間の文字色と進捗バー（と外枠）を警告色に変更
- TimeUp 中は警告色で `0:00` を0.5秒周期で点滅（消灯側は完全に消さず薄く残す）
- TimeUp 中は経過時間の代わりに「♪ クリックで止める」と表示し、解除方法を示す
- カウントアップは警告色にしない（ティールのまま）。Stopped では「■ 停止中 ・ クリックで閉じる」をティールで表示する

### 4.8 デザイン

- 配色は初音ミクのイメージカラーに寄せる。主役の色はティール `#39C5BB`、下地は衣装のグレーを暗くした色、警告色はピンク `#FF5AA5`
- タイマー本体・右クリックメニュー・設定画面・トレイメニューは暗い下地で統一する（設定画面のタイトルバーも Windows 11 では同じ色にする）
- 時間表示の数字は Bahnschrift、本文は Segoe UI Variable ＋ Yu Gothic UI
- 進捗バーは音量メーターのような目盛り区切りで、残り時間と同じくらい目に入る太さ（基準サイズで高さ12DIP）にする
- 角は「角張っているが角が立たない」程度に小さく丸める（大きな面は R4、ボタン・入力欄は R3 程度）。丸い部品（トグルやスライダーのつまみなど）も角の丸い四角にする
- プリセットボタンは動作中の画面と同じく、暗い板に白い数字＋ティールの光彩で表示し、下端のティールのラインでボタンであることを示す。数字だけをボタンの中央に置き、単位（分・秒）は数字の右に小さく添える
- 色・フォント・コントロールの見た目は `Themes/` の XAML にまとめる

### 4.9 時間を指定して開始

右クリックメニューの「タイマー（時間指定）...」で開く小窓。

```
┌ 時間を指定して開始 ─────────────── ✕ ┐
│                                      │
│   [ 0]時間   [25]分   [00]秒         │
│        ↑↓ キー・ホイールで増減       │
│                                      │
│              [キャンセル] [▷ 開始]   │
└──────────────────────────────────────┘
```

- 通常のウィンドウ（タイトルバーあり、サイズ変更不可、最前面、タスクバーに出さない）。タイトルバーは設定画面と同じ暗い配色
- タイマーのすぐ上に右端をそろえて表示する。上に入らなければ下、どちらにも入らなければ作業領域内に収める
- 入力は時・分・秒の3欄（0〜23時間、0〜59分、0〜59秒。合計1秒〜23:59:59）。空欄は0とみなす。全角数字も受け付ける
  - 開いた時は「分」の欄を全選択した状態。欄に入ると全選択されるので、そのまま打ち直せる
  - ↑↓キー・マウスホイールで1ずつ増減（0〜上限で止まり、繰り上がりはしない）
  - 範囲外・数字以外の欄はピンクの枠（理由はツールチップ）。合計0なら「1秒以上を指定してください」を表示。どちらも開始できない
- Enter または「開始」でカウントダウンを開始して閉じる。Esc・「キャンセル」・✕ で閉じる
- 開始した時間を記憶し、次に開いた時の初期値にする（初回は5分）
- 小窓を開いている間にタイマーが動き出した場合（ホットキーなど）は開始できず、「タイマーの動作中は開始できません」を表示する
- 開始後の動作はプリセットと同じ（警告色・TimeUp・音・通知）

### 4.10 時刻を指定してアラーム

右クリックメニューの「アラーム（時間指定）...」で開く小窓。指定した時刻までのカウントダウンとして動く（待っている間はタイマー本体を使い、ほかのタイマーは開始できない）。

```
┌ 時刻を指定してアラーム ──────────── ✕ ┐
│                                      │
│          [ 7]時   [30]分             │
│   今日の 7:30 に鳴ります（あと 1時間12分）│
│        ↑↓ キー・ホイールで増減       │
│                                      │
│             [キャンセル] [🔔 セット]  │
└──────────────────────────────────────┘
```

- 窓の作り・位置・入力欄の操作（全選択、↑↓キー・ホイールで増減、全角数字可、範囲外はピンクの枠）は 4.9 と同じ
- 入力は時・分の2欄（24時間制。0〜23時、0〜59分）。空欄は0とみなす。開いた時は「時」の欄を全選択した状態
- 今日のその時刻を過ぎていれば（同じ時刻も含む）翌日のその時刻に鳴らす。鳴る時刻を「今日の 7:30 に鳴ります（あと 1時間12分）」「明日の 7:30 に鳴ります（あと …）」のように表示し、開いている間は1秒ごとに更新する（残りは分単位に切り上げ）
- Enter または「セット」で開始して閉じる。Esc・「キャンセル」・✕ で閉じる
- セットした時刻を記憶し、次に開いた時の初期値にする（初回は開いた時刻の次の正時）
- 1回だけ鳴る（毎日の繰り返しはしない）。アプリを終了するとアラームも消える
- 待つ時間はセットした瞬間の現在時刻から求め、以降は他のカウントダウンと同じく開始時刻との差分で計る（11章）。スリープ中に時刻を過ぎていれば復帰時に TimeUp
- 本体には残り時間を大きく、その下にベルのアイコンと「7:30 にアラーム」を表示する
- 小窓を開いている間にタイマーが動き出した場合は 4.9 と同じく開始できない
- 鳴ってからの動作はプリセットと同じ（警告色・TimeUp・音）。通知の文言は「時間です / 7:30 のアラームです。」

## 5. タイムアップ時の動作

1. TimeUp 状態へ遷移
2. 選択中の音を音量設定に従ってループ再生（音量0なら鳴らさない）
3. 自動停止時間（デフォルト60秒）経過で音のみ停止。表示は TimeUp のまま維持
4. トースト通知（トレイのバルーン通知）を表示（設定でON/OFF、デフォルトON）。文言は「時間です / 25分のタイマーが終了しました。」（時間は「1時間30分」「1分30秒」のように0の単位を省いて表す）。アラームでは「時間です / 7:30 のアラームです。」
5. ウィンドウ上の左クリック（グリップ除く）またはキャンセルホットキーで、音を止めて Idle に戻る

全画面アプリによる自動非表示中にタイムアップした場合も、音とトースト通知は通常通り出す。ウィンドウは全画面アプリの上に強制表示しない。

## 6. 音声

### 6.1 デフォルト音源

- Windows 標準のアラーム音（`C:\Windows\Media\Alarm01.wav`〜`Alarm10.wav`）のうち存在するものを一覧に表示
- フォールバックとして、アプリに埋め込んだビープ音（WAV）を1つ用意する
- デフォルト選択：`Alarm01.wav`（存在しなければ埋め込みビープ）

### 6.2 ユーザー音源の追加

- 設定画面の「追加...」ボタンからファイル選択（対応形式：`.wav` / `.mp3`）
- 選択したファイルは `%APPDATA%\DesktopTimer\sounds\` にコピーして管理する（元ファイルの移動・削除の影響を受けないため）
- ユーザー追加音源のみ削除可能
- 各音源に試聴ボタン（もう一度押すと停止）

### 6.3 再生

- NAudio でループ再生し、音量は 0〜100% で制御
- 選択中の音源ファイルが存在しない場合は埋め込みビープで代替

## 7. ショートカットキー

| 動作 | デフォルト |
|---|---|
| プリセット1を開始 | `Ctrl+Alt+1` |
| プリセット2を開始 | `Ctrl+Alt+2` |
| キャンセル / TimeUp解除 | `Ctrl+Alt+0` |

- キャンセルのホットキーは、カウントアップの計測中は「停止」、Stopped では「閉じる」として働く（右クリックメニューのキャンセル項目と同じ）
- 時間指定・アラーム・カウントアップの開始にはホットキーを設けない

- グローバルホットキー（アプリ非アクティブ時も有効）
- 設定画面で変更可能（キー入力を受け付けるボックスで修飾キー＋キーを登録）
- 登録失敗時（他アプリと競合）は設定画面に警告を表示し、そのホットキーは無効として扱う

## 8. 表示制御

### 8.1 透明度

- ウィンドウ全体の不透明度を 30%〜100% で設定（デフォルト100%）

### 8.2 全画面アプリ検出時の自動非表示

- フォアグラウンドウィンドウが、タイマーと**同じモニター**の全域を覆っている場合にタイマーを非表示にする
- デスクトップ（`Progman` / `WorkerW`）やシェルウィンドウは全画面扱いしない
- 判定は1秒周期のポーリングで行う（`GetForegroundWindow` + `GetWindowRect` + `MonitorFromWindow`）
- 全画面状態が解除されたら再表示
- 設定でON/OFF（デフォルトON）

### 8.3 マルチモニタ

- 位置はスクリーン座標とモニター識別情報で保存する
- 起動時に保存位置がどのモニターの作業領域にも収まらない場合（モニター切断等）、プライマリモニター右下に配置
- 表示中にモニター構成が変わった場合（`SystemEvents.DisplaySettingsChanged`）も同じ判定を行う

## 9. タスクトレイ・起動

- タスクトレイに常駐（アイコン必須）
- トレイの右クリックメニュー：表示/非表示、キャンセル（カウントアップの計測中は「停止」）、設定...、位置をリセット、終了
- トレイアイコンのダブルクリック：表示/非表示の切替
- Windows 起動時の自動起動：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` への登録で実現（設定でON/OFF、デフォルトON）
- 多重起動防止（名前付き Mutex）。2つ目の起動時は既存インスタンスを表示状態にして終了

## 10. 設定

### 10.1 設定項目

| 項目 | デフォルト | 範囲 / 備考 |

| プリセット2の時間 | 30分 | 1〜180分（分単位） |
| タイムアップ音 | Alarm01.wav | デフォルト音源 + ユーザー追加音源 |
| 音量 | 80% | 0〜100%（0で無音） |
| 音の自動停止時間 | 60秒 | 5〜600秒 |
| トースト通知 | ON | |
| 警告色に変わる残り時間 | 1分 | 0〜10分（0で無効） |
| 不透明度 | 100% | 30〜100% |
| サイズ（スケール） | 100% | 50〜300% |
| 全画面時に自動非表示 | ON | |
| Windows起動時に自動起動 | ON | |
| ホットキー（3種） | 7章参照 | |

### 10.2 設定画面

- 通常のウィンドウ（タイトルバーあり、最前面ではない）
- 変更は即時反映し、即時保存（OK/キャンセルボタンは設けない）
- 「すべてデフォルトに戻す」ボタン

### 10.3 保存

- 保存先：`%APPDATA%\DesktopTimer\settings.json`
- 保存内容：10.1 の全項目 + ウィンドウ位置・モニター情報 + 「時間を指定して開始」で前回指定した時間（`LastCustomSeconds`）+ 「時刻を指定してアラーム」で前回指定した時刻（`LastAlarmMinutes`。0:00 からの分、未指定は null）。この2つは設定画面には出さず、「すべてデフォルトに戻す」でも戻さない
- ファイルが壊れている場合はデフォルト値で起動し、壊れたファイルを `settings.json.bak` に退避する

## 11. タイマー精度

- 残り時間は開始時刻（`Stopwatch` または単調増加時刻）との差分から算出する。タイマーイベントの回数を数える方式にしない（ずれ防止）
- 表示更新は200ms周期程度
- PCのスリープ復帰後も、実時間ベースで残り時間を再計算する（スリープ中に0を過ぎていれば復帰時に TimeUp）

## 12. 対象外（v1では実装しない）

- 一時停止・延長
- タスク名の入力
- 使用履歴・統計
- ポモドーロの自動連続サイクル
- 配布用インストーラ・自動更新
