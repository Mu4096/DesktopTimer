# 他 PC での利用手順を README に追記

- 日付：2026-10-13
- 種別：ドキュメント
- 関連する仕様書の章：なし

## 背景・目的

別の PC でもこのタイマーを使いたいという要望。相手の PC に .NET を入れずに済むよう、ランタイムを含めた単一 exe を出力して持っていく方法を README に残す。

## 変更内容

- `README.md` に「他の PC で使う」節を追加
  - `dotnet publish` に `-r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true` を付けて、ランタイムを含めた単一 exe を出力する
  - 出力先はリポジトリの外（`C:\work\creative\DesktopTimer-portable`）とした。`.gitignore` に含まれないため、リポジトリ内に出すと未追跡ファイルになる
  - 置き場所、SmartScreen の警告、設定・音源（`%APPDATA%\DesktopTimer\`）の引き継ぎ、更新方法を記載
- コードと仕様書は変更なし（仕様書 1章の「配布は想定しない」は、他者への配布の話なので変えていない）

## 確認

- 上記の publish コマンドを一時フォルダへの出力で実行し、警告・エラーなしで完了することを確認。出力は `DesktopTimer.exe`（約 170MB）と `DesktopTimer.pdb` の 2 ファイルだった
- 出力した exe を他 PC で起動する確認はまだしていない（ユーザーが実施予定）
